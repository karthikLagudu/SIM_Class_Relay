Classroom workflows

Student workspace

See deadlines, submit text or attachments, report progress, ask for help, and read feedback.

Teacher workspace

Draft assignments from text or dictation, choose recipients, change deadlines, and review submissions.

Coordinator workspace

Manage teaching teams and enrollments, review school-wide submissions, and remove school access while retaining work history.

Telegram menu

Link an account to see role-specific actions, assignment notices, reminders, and feedback in a private chat.

Live updates

Open work and review pages pick up changes made in Telegram. Unsent browser edits stay in place.

Reminders

Scheduled reminders reflect assignment status, current deadlines, and school quiet hours.

ARCHITECTURE

Shared application services

Transport adapters delegate to shared domain services. Every supplied ID passes server-side scope checks. Every student state change passes one central transition map. Model output is validated before it can become domain input.

Run Class Relay locally

Open the local sign-in page and select Show demo accounts. The full demo guide includes three schools and additional classroom workflows.

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
if (!(Test-Path .env)) { Copy-Item .env.example .env }
python -m scripts.seed
$env:DEMO_MODE = 'true'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8767 --no-access-log
